LuxVision AI Architect is a state-of-the-art architectural visualization platform that empowers users to generate, edit, and manage high-end luxury house designs using the power of **Google Gemini AI**. With a seamless glassmorphism interface and integrated Google Drive cloud storage, it's the ultimate tool for modern architects and design enthusiasts.

---

## ✨ Key Features

- **🚀 AI Image Generation**: Create stunning architectural renders from natural language descriptions.
- **🪄 Intelligent Refinement**: Edit existing designs by simply describing the changes (e.g., "add an infinity pool" or "change to night lighting").
- **💡 AI Prompt Suggestions**: Get inspired with context-aware prompt suggestions generated by Gemini.
- **☁️ Google Drive Sync**: Automatically backup your favorite designs to a dedicated Google Drive folder without complex login flows.
- **🖼️ Built-in Gallery**: Manage your local history and saved gallery in a beautiful, organized view.
- **📱 Responsive & Premium UI**: A sleek, dark-themed interface designed for professional aesthetics and ease of use.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v16+)
- A Google Cloud Project with the **Gemini API** enabled.
- A Google Account for Drive integration.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/luxvision-architect.git
cd luxvision-architect

# Install dependencies
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory and add your credentials:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
VITE_DRIVE_UPLOAD_URL=your_google_apps_script_url_here
```

### 4. Running the App
```bash
npm run dev
```

## 🏗️ Google Drive Setup (No-Login Integration)

LuxVision uses a custom Google Apps Script bridge to allow uploads to a specific folder without requiring every user to sign in.

1.  Create a new folder in your **Google Drive**.
2.  Copy the **Folder ID** from the URL.
3.  Go to [script.google.com](https://script.google.com) and create a new project.
4.  Copy the content of `code.gs` from this repository into the script editor.
5.  Update the `FOLDER_ID` in the script's `CONFIG` object.
6.  Click **Deploy** -> **New Deployment**.
    - **Type**: Web App
    - **Execute as**: Me
    - **Who has access**: Anyone
7.  Copy the **Web App URL** and paste it into your `.env` file as `VITE_DRIVE_UPLOAD_URL`.

## 📖 Usage Instructions

- **Generate**: Start with the default prompt or type your own description of a luxury house.
- **Edit**: Click on an image, type a modification (e.g., "Modern black wood materials"), and click **Apply**.
- **Save**: Click **Save to Gallery**. If "Sync to Drive" is checked, it will also be uploaded to your cloud folder.
- **History**: Use the sidebar to switch between your current session history, saved local gallery, and cloud files.
- **Download**: High-resolution versions can be downloaded directly via the download icon on any image.
